# Picky Lite

> 一个轻量级的 After Effects 图层选择面板，灵感来自 [Picky](https://motionfun.net/tools/petals)。
> 纯 ExtendScript 实现，无外部依赖，支持停靠面板。

![preview](preview.png)

## ✨ 功能

### 按类型全选
点击按钮即可全选合成内对应类型的所有图层：

- **文本** / **形状** / **纯色**
- **图片** / **视频** / **音频**
- **预合成** / **空对象** / **摄像机**
- **灯光** / **调整图层** / **含音频**

### 匹配活动图层 · 属性
- **同类型** — 选中所有与活动图层类型相同的图层
- **同标签色** — 选中所有与活动图层标签颜色相同的图层

### 匹配活动图层 · 链接
- **子链接** — 递归选中活动图层的所有子孙图层
- **父链接** — 沿层级向上选中所有祖先
- **父子链** — 祖先 + 后代，完整路径
- **全部关联** — 整棵层级树（根节点下的所有分支）

### 选择操作
- **全选 / 取消全选** — 同一个按钮，状态自动切换
- **反选** — 反转当前选择状态

## 🖥 兼容性

- After Effects **CC 2015** 及以上
- Windows / macOS
- 无需额外依赖，无需联网

## 🎯 使用技巧

- 「匹配活动图层」系列按钮，建议**先在时间轴里选中一个图层**再点按钮。脚本会自动回退到 `selectedLayers[0]` 和缓存的参考图层，避免因焦点丢失导致活动图层为空。
- 「全部关联」适合处理复杂的父子层级结构（如角色绑定、摄像机装配）。

## 🛠 技术细节

- 纯 **ExtendScript (JSX)**，无 CEP 依赖
- 基于 `ScriptUI` 构建停靠面板
- 文件编码：**UTF-8 with BOM**（避免中文乱码）
